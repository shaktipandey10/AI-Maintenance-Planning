2. Re-queries technician data (which includes updated availability)
3. Runs DeterministicPlanningScheduler against modified data
4. Verifies scheduler's `HasAvailability()` check enforces intervals:
   ```csharp

       availability.AvailableFrom <= start && availability.AvailableTo >= end)
   ```
