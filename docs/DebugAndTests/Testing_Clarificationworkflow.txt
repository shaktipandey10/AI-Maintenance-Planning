### **Step 1: Create a Planning Request (First Attempt)**

**URL:** `http://localhost:5173`

**Fill in the form:**

- **Asset IDs:** `P-101`
- **Maintenance Window:** (leave empty)

**Click:** "Create Planning Job"

**Expected Result:**
- Success message appears: `Planning job created successfully! Job ID: {UUID}`
- Copy the Job ID
- Green "Check Status" button appears

---

### **Step 2: Wait for Job to Complete**

The backend worker will process the job. This takes time depending on Ollama response time (usually 30-60 seconds).

You can monitor progress by:
1. Scrolling to "Get Planning Job Status" section
2. Paste the Job ID
3. Click "Get Status" repeatedly to check progress
4. Watch CurrentStep change: `Queued` → `Processing` → `Completed`

---

### **Step 3: View Clarification Section (When Outcome = ClarificationRequired)**

**Expected when job completes:**
- Status: `Succeeded`
- Current Step: `Completed`
- **Orange Section Appears:** "Clarification Required"

**This section will show:**

1. **Planning Summary Box:**
   - Maintenance Intent: `P-101 Bearing Replacement and Inspection`
   - Scope: (the analyzed scope)
   - Proposed Assets: `P-101`
   - Proposed Tasks: (task IDs)

2. **Questions Box:**
   - List of clarification questions (e.g., "Spare part availability check")

---

### **Step 4: Submit Clarification**

**In the Clarification Required section:**

**Fill in:**
- **Maintenance Window ID (Required):** `window-2024-Q1`
  - (Can be any value - this is what the planner was missing)
- **Additional Context (Optional):** `Bearing replacement is critical for P-101 pump operation`

**Click:** "Submit Clarification"

**Expected Result:**
- Green success message: `Clarification submitted successfully. Job has been re-queued for planning.`
- Status section updates:
  - Status: `Queued` (changed from `Succeeded`)
  - CurrentStep: `Queued`
  - AttemptCount: `1` (reset from original value)

---

### **Step 5: Monitor Re-Planning**

**Check status again** by scrolling to "Get Planning Job Status" section:
- Click "Get Status" button (or manually enter Job ID again)
- Watch for updates:
  - Status: `Queued` → `Running` → `Succeeded` or `Completed`
  - CurrentStep: `Processing` → `Completed`
  - CompletedAtUtc: Updated timestamp
  - ResultPayload: New planning result (may still show clarification or show candidates)

---

### **Step 6: Test Error Cases**

#### **Test 1: Submit Clarification Without WindowId**
- Leave "Maintenance Window ID" empty
- Click "Submit Clarification"
- **Expected:** Error message: `Maintenance Window ID is required`

#### **Test 2: Submit with Invalid Job ID**
- Get Status with non-existent UUID
- **Expected:** Error message: `Job not found: {UUID}`

#### **Test 3: Submit Clarification on Non-Clarification Job**
- Create a job that completes with outcome=`CandidatesGenerated` (if you get lucky)
