## ✅ AT03 Regression Fixed

### **Issue**
Test `ExecuteAsync_CrossDocumentConflictingEvidenceDetected_ReturnsDataUnavailableWithViolation` was failing because the `IsExplicitConflict()` method wasn't correctly matching asset IDs with different formats.

### **Root Cause**
The regex extraction matched "P101" (without dash) from document ID "MAN-P101-001", but the evidence excerpt contained "p-101" (with dash). The string Contains check failed:
- Expected: `lowerExcerpt.Contains("p101")`
- Actual excerpt: "do not substitute this scope for the p-101 bearing..."
- Result: "p-101".Contains("p101") → false ❌

### **Fix Applied**
[PlanningWorkflow.cs:554-574](src/MaintenancePlanner.Application/Planning/PlanningWorkflow.cs#L554-L574)

Added support for both "P101" and "P-101" formats:
```csharp
var assetId = assetMatch.Value.ToLowerInvariant();
var assetIdWithDash = System.Text.RegularExpressions.Regex.Replace(assetId, @"^p(\d{3})$", "p-$1");
return lowerExcerpt.Contains(assetId) || lowerExcerpt.Contains(assetIdWithDash);
```
